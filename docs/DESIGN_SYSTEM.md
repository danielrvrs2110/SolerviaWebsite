# Solervia Design System

## Direction

Solervia should feel calm, capable, direct, and useful to a Mexican PyME. The
interface uses editorial spacing and operational details instead of generic SaaS
cards, gradients, decorative dashboards, or invented proof.

## Tokens

- Primary: `#0F5C5A`
- Primary dark: `#0A3D3C`
- Commercial accent: `#F4A62A`
- Background: `#F7F5EF`
- Surface: `#FFFFFF`
- Text: `#1F2523`
- Secondary text: `#66706C`
- Success: `#2F8F5B`
- Error: `#B94A48`

The amber accent is reserved for high-intent actions, focus, and small moments
of emphasis. Borders organize content; shadows are used sparingly.

## Typography

- Display: Bricolage Grotesque
- Body and UI: Source Sans 3
- Headings use tight tracking and responsive fluid sizes.
- Labels and eyebrows use compact uppercase text with wide tracking.

## Components and behavior

- Buttons use a six-pixel radius, at least 52 pixels of height, and visible focus.
- Sections use generous but responsive vertical rhythm.
- Lists and dividing lines replace unnecessary cards.
- Mobile layouts reorder into a clear single column, not a scaled desktop page.
- Motion is short and functional, and respects `prefers-reduced-motion`.
