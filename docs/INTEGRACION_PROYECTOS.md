# Integración editorial de proyectos

Actualizado: 10 de noviembre de 2026.

Este sitio es independiente de las aplicaciones descritas. El contenido público se basa en sus repositorios; no hay imports, API, autenticación ni datos compartidos entre ellos.

| Fuente | Evidencia consultada | Uso en la web | Límite público |
| --- | --- | --- | --- |
| PedidoFlow (`Solervia/`) | `PEDIDOFLOW_MASTER.md`, `docs/TASKS.md`, `docs/PROJECT.md`, README y código del catálogo | Ficha de producto en desarrollo: destinatario, problema, base de acceso y catálogo implementado | Interpretación, revisión y ciclo completo de pedidos siguen pendientes; no se presenta como SaaS disponible |
| Solervia Sales Agent (`SSA/`) | README, `docs/ACTIVACION.md`, `docs/INTEGRACIONES.md` y componentes | Ficha de demostración privada: CRM, preparación y aprobación de campañas | No se anuncian comunicaciones reales ni integraciones verificadas con proveedores |
| ERP de carpintería (`Proyectito/carpinteria-erp/`) | README, `VERIFICACION.md`, `ops/VERCEL.md` y código de módulos | Referencia anónima de capacidades en Custom | Sin nombres de usuarios, URLs privadas, cifras, capturas, cuentas ni afirmación de disponibilidad pública |

Los repositorios fuente no aportan fotografías, logotipos comerciales o capturas aptas para la web pública. Sus iconos de plantilla y las evidencias de interfaces privadas no se copiaron. El sitio conserva su logotipo y paleta propios y usa diagramación CSS para comunicar el flujo.

El formulario de consulta solo valida en el navegador. El propietario confirmó que aún no existe un correo público de Solervia. Para captar solicitudes reales se necesita acordar un canal de recepción, validación en servidor, protección contra abuso, política de datos y aviso de privacidad antes de activar el envío.
